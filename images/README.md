# Images

Upload project and program photos to this folder to be used. 

## How to Add a Photo

1. Upload the photo to this `images` folder.

2. Copy or note the photo's filename.

   Example:
   `river-watch.jpg`

3. Open `map.js`.

4. Find the project or program you want to add the photo to.

5. Find the line:

   `photo: "",`

6. Add the image path between the quotation marks.

   Example:

   `photo: "images/river-watch.jpg",`

7. Commit/save the changes.

The photo will automatically appear on the map.

## If There Is No Photo

Leave the photo field blank:

`photo: "",`

The map will automatically display a "Photo coming soon" placeholder.

## Important

Do not delete the quotation marks or comma around the `photo` field in `map.js`.
